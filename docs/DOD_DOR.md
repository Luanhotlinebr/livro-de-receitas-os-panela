# Acordos de Qualidade da Equipe

## Definition of Ready (DoR)

Antes de começar uma história de receita ou melhoria, confira a Issue:

- [ ] O título identifica a receita ou melhoria proposta.
- [ ] A descrição usa o formato **Como / quero / para que** e cita uma persona de [PERSONAS.md](PERSONAS.md).
- [ ] A Issue indica a categoria da receita ou a página afetada pela melhoria.
- [ ] A Issue contém pelo menos dois critérios de aceitação verificáveis em checklist.
- [ ] A Issue tem a label `user-story` e referencia o épico pai pelo número. A label `enhancement` pode complementar a classificação de uma melhoria.

## Definition of Done (DoD)

Antes de considerar uma entrega concluída, confira o resultado:

- [ ] Os critérios de aceitação da Issue foram verificados.
- [ ] O conteúdo alterado foi revisado quanto à ortografia e à formatação Markdown.
- [ ] As receitas alteradas seguem o padrão do [guia de contribuição](../CONTRIBUTING.md). Novas receitas aparecem no `menu.md` e no índice da categoria correspondente.
- [ ] Os links adicionados ou alterados foram abertos e apontam para os destinos esperados.
- [ ] O Pull Request está vinculado à Issue e recebeu pelo menos três aprovações formais de integrantes diferentes, conforme o [guia de contribuição](../CONTRIBUTING.md).
- [ ] O Pull Request foi integrado à `main`, com todos os conflitos resolvidos.
