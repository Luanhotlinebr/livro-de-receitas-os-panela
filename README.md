# Livro de Receitas Colaborativo

Este projeto reúne receitas em Markdown, organizadas por categoria e
desenvolvidas colaborativamente pela equipe [nome da equipe]. A atividade
também permite praticar o controle de mudanças com Git e GitHub.

## Acesse o livro

Consulte o [menu de receitas](menu.md) para navegar pelas categorias
e encontrar as receitas disponíveis.

## Como contribuir

1. Abra uma issue informando a receita e a categoria.
2. Crie uma branch a partir da `main` atualizada, usando o padrão
   `feature/<categoria>-<nome-da-receita>`.
3. Adicione a receita na pasta correspondente e atualize o `menu.md`.
4. Envie suas alterações e abra um Pull Request vinculado à issue.
5. Solicite a revisão dos colegas. O PR precisa de pelo menos três
   aprovações antes de ser integrado à `main`.

Consulte o [guia de contribuição](CONTRIBUTING.md) para conhecer
os padrões e o fluxo completo.
